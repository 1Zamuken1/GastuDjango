Formato del archivo CSV

El archivo debe tener encabezados en la primera fila. Las columnas reconocidas son:

Columna Obligatorio Valores aceptados
nombre Si Texto libre (max 100 caracteres)
tipo Si INGRESO, EGRESO, AHORRO
descripcion No Texto libre (max 255 caracteres)
activo No true / false (por defecto: true)

Ejemplo de contenido valido: 

nombre,tipo,descripcion,activo
Salario,INGRESO,Pago mensual,true
Alimentacion,EGRESO,Compras de mercado,true
Fondo Emergencia,AHORRO,Reserva de seguridad,true

Las categorias que ya existen en el sistema (mismo nombre y tipo) seran omitidas automaticamente.
